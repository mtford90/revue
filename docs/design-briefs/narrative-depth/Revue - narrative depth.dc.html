Theme slots

None required. The excerpt header uses panel (the surface hunk headers and file headers already use), its rule uses lineNumberFg — the same quiet grey as the gutter it stands in for, its label and line numbers use muted and lineNumberFg, and its body sits on contextBg — which is what makes it read as scenery: it is literally the unstyled page. If you later want the whole band tinted, that is one new derivation slot, excerptBg: text blended toward the background at 6% on dark themes and 3% on light, floored so text still clears 4.5:1 — weaker than any diff tint by construction, so an excerpt can never look like a change.
