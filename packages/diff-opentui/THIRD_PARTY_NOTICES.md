## Hunk

This package selectively adapts OpenTUI diff-body and compact file-header presentation concepts
from [Hunk](https://github.com/modem-dev/hunk) v0.15.3, commit
`3a2ba1c4c0580f0056bf67b031fb25f2186f35a3`. Studied sources are
`src/opentui/HunkDiffBody.tsx` and `src/ui/components/panes/DiffFileHeaderRow.tsx`.

Local modifications mount `@revue/diff` visual plans, map Revue themes, and add exact side-aware
pointer selection, context callbacks, React-valued attachments, expansion controls, renderable IDs,
measurement and row-window mounting. Hunk is not a runtime dependency.
